How it works

A pose model watching every joint, live

Your Ball Club runs Google's MoveNet pose-detection model directly in the browser via TensorFlow.js. It maps 17 keypoints — shoulders, elbows, hips, knees — on every frame and turns that into the angles and timing that make up a delivery.

Because the model runs on-device, the video never has to leave the browser to be analyzed. Point a phone, a laptop webcam, or a dedicated high-speed camera at the mound and the overlay starts drawing immediately.

  • Skeleton overlay tracks 17 body keypoints in real time
  • Kinematic sequence chart shows hip-shoulder separation timing
  • Manual three-point angle tool for anything the model misses
  • Motion trajectory path traces the arm path across the delivery

Where the data lives

Built for a coach filming players, not a data company

Pose detection happens entirely on-device — the camera feed is never uploaded anywhere to be analyzed. What you choose to save is scoped to your own roster.

  • Sign-in required — no anonymous access to a roster
  • Each coach sees only their own players by default
  • Optional team sharing for coaching staffs
  • Self-hostable as a packaged app on your own server
